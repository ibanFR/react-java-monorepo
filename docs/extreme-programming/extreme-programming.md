# Extreme Programming
{: .no_toc }

Extreme Programming (XP) is the engineering discipline this project draws on to keep
the codebase healthy, changeable, and well-tested — test-driven development, continuous
integration, refactoring, simple design, and collective code ownership.
{: .fs-6 .fw-300 }

This section is organized using the Diataxis framework so you can quickly find the
right document type for the task at hand — Tutorials for learning by doing, How-to
Guides for goal-oriented tasks, Reference for facts and checklists, and Explanation
for concepts and rationale.
