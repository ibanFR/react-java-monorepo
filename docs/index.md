This project is a full-stack monorepo designed to provide a natural migration path from traditional Java EE (JSF/CDI)
environments to modern, cloud-native development. It features a Quarkus-based backend (Java 21, REST, Hibernate, CDI)
and a React + TypeScript frontend, prioritizing minimal learning curve, code reusability, and cloud-native principles.

## Project Goals 🎯

1. Understand the architecture and design principles of a modern full-stack monorepo: Gain hands-on experience with
   Quarkus, React, and TypeScript in a cohesive project.
2. Apply the [Agile Development Model](https://ibanfr.github.io/agile-development-model/master/) in a production-like
   environment.
3. Learn and experiment with harness engineering: Customize coding agents with instructions, skills, and workflows to

## Understand the architecture and design principles of a modern full-stack monorepo

Learn how the backend and frontend are organized, how modules interact, and how Domain-Driven Design (DDD) and
cloud-native principles are applied to create scalable, maintainable enterprise applications.

Work directly with modern technologies: build REST APIs with Quarkus, create interactive UIs with React, and leverage
TypeScript for type safety and maintainability across the stack.

## Apply the Agile Development Model in a production-like environment

Experience how agile practices are integrated into the development workflow, including iterative delivery, testing, and
collaboration, using real-world tools and processes.

## Learn and experiment with harness engineering

Harness engineering is the practice of customizing, extending, and integrating coding agents and developer automation
tools to fit your team's unique workflows and maximize productivity. In this project, you will:

- Explore how to extend and adapt coding agents (such as Copilot, GPT-based tools, or custom agents) for your team's
  unique workflows.
- Develop and test agent instructions, reusable skills, and prompt engineering patterns for code generation,
  refactoring, and review.
- Integrate agent-driven automation into the development lifecycle (e.g., CI/CD, code review, documentation, testing).
- Evaluate the impact of harness engineering on developer experience, code quality, and team velocity.

This goal encourages experimentation with agent configuration, prompt design, and workflow automation to create a more
effective and enjoyable development environment.
